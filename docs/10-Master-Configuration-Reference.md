# 📜 10. Master Configuration Reference

Complete breakdown of PinataSpectra configuration files.

---

## 📁 Configuration File Overview

1. **`config.yml`:**
   * Database storage backend (`SQLITE`, `MYSQL`, `REDIS`).
   * Particle LOD settings and max render distances.
   * Auto-Scheduler timings and countdown thresholds.
   * Vote Goal parameters and BossBar styling.
   * `CandySweeperService` purge options.

2. **`pinatas.yml`:**
   * Piñata definitions (`default`, `golden_llama`, `cosmic_unicorn`, etc.).
   * Base health, scale, animation styles, Base64 head textures, and combat phase triggers.

3. **`drops.yml`:**
   * Loot tables with percentage chances, custom items, Vault money rewards, and console commands.

4. **`messages.yml`:**
   * Translatable text bundle with full Hex (`<#a855f7>`), MiniMessage, and PlaceholderAPI support.
