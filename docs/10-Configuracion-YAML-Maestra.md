# 📜 10. Configuración YAML Maestra

PinataSpectra ofrece un control total sobre cada detalle del plugin mediante archivos YAML claros y auto-explicativos.

---

## 📁 Resumen de Archivos de Configuración

1. **`config.yml`:**
   * Ajustes de almacenamiento (SQLite / MySQL / Redis).
   * Sistema de LOD de partículas y rangos de visibilidad.
   * Configuración de los Bates de Fiesta (`bats.yml`).
   * Parámetros del Auto-Scheduler y metas de votos.
   * Ajustes del barredor de dulces `CandySweeperService`.

2. **`pinatas.yml`:**
   * Definición de todos los tipos de piñatas (`default`, `golden_llama`, `cosmic_unicorn`, etc.).
   * Modelos, texturas Base64 de cabezas, multiplicadores de salud por tier y fases de combate.

3. **`drops.yml`:**
   * Tablas de botín con probabilidades porcentuales, ítems personalizados, comandos ejecutables por consola y recompensas de economía Vault.

4. **`messages.yml`:**
   * Todos los mensajes del plugin traducibles, con soporte para MiniMessage, códigos de color Hex (`<#a855f7>`) y Placeholders.
