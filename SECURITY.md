# Security Policy & Vulnerability Reporting

## Supported Versions
| Version | Supported |
|---|---|
| 1.0.x-RELEASE | ✅ Yes |
| < 1.0.0 | ❌ No |

## Reporting a Vulnerability
If you discover a security vulnerability or anti-abuse loophole in PinataSpectra (such as candy duplication, state-machine bypassing, or permission escalation):
1. **Do NOT disclose it publicly on public GitHub issues.**
2. Send a private report to: `dr8553097@gmail.com` or contact Dafealru directly via official support channels.
3. Include a detailed reproduction scenario and server environment.

We aim to address critical security and economy integrity reports within 24 hours.
