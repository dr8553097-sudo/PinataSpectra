# 📜 10. Master Configuration Reference

This guide provides an exhaustive, line-by-line specification for all configuration files generated by **PinataSpectra — Sovereign Edition**.

---

## 📄 1. `config.yml` (Core Engine Settings)

```yaml
# ==============================================================================
#                 PinataSpectra 3D — Master Configuration
#                      Edition: Sovereign Commercial
# ==============================================================================

# Database Storage Engine
# Supported backends: SQLITE, MYSQL, MARIADB, REDIS
database:
  type: "SQLITE"                  # Default: SQLITE (zero setup needed)
  sqlite:
    file: "database.db"
  mysql:
    host: "127.0.0.1"
    port: 3306
    database: "pinataspectra"
    username: "root"
    password: "password123"
    pool:
      maximum-pool-size: 10       # Max active connections in HikariCP pool
      minimum-idle: 2             # Min idle connections maintained
      connection-timeout: 30000   # Milliseconds before connection timeout
      idle-timeout: 600000        # Max idle lifetime in milliseconds

# Particle Level of Detail (LOD) Safeguard
particle-lod:
  enabled: true
  close-distance: 8.0             # Radius for Tier 1 Full-Detail rendering
  medium-distance: 24.0           # Radius for Tier 2 Half-Detail rendering
  far-distance: 48.0              # Radius for Tier 3 Boundary-Only rendering
  max-concurrent-particles: 120   # Hard limit per tick to prevent low-end client FPS drops

# Ground Perimeter Runic Circles
runic-circle:
  enabled: true
  radius: 4.5                     # Radius in blocks of the floor circle
  rotation-speed: 2.5             # Degrees rotated per tick
  particle: "PORTAL"              # Particle type (PORTAL, ENCHANT, FLAME, SOUL_FIRE_FLAME)

# Candy Sweeper Service (Economy Anti-Dupe Protection)
candy-sweeper:
  enabled: true                   # Purges leftover candies upon event conclusion
  sweep-inventories: true         # Audits online player inventories
  sweep-enderchests: true         # Audits player enderchests
  sweep-ground-entities: true     # Removes dropped candy item entities in world

# Automated Timed Scheduler
scheduler:
  enabled: true
  interval-minutes: 120           # Time between automated spawns
  countdown-warnings: [900, 300, 60, 30] # Broadcast warnings at 15m, 5m, 1m, 30s
  default-pinata: "default"
  default-tier: "tier_1"

# Community Vote Party Goal
vote-party:
  enabled: true
  votes-required: 100             # Total server votes needed to trigger event
  bossbar:
    enabled: true
    title: "<gradient:#a855f7:#00f0ff><bold>VOTE PARTY</bold></gradient> <gray>({current}/{required})</gray>"
    color: "PURPLE"               # PINK, BLUE, RED, GREEN, YELLOW, PURPLE, WHITE
    style: "SEGMENTED_10"         # PROGRESS, NOTCHED_6, NOTCHED_10, NOTCHED_12, NOTCHED_20
```
